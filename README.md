# Sera Glacier

Deploy-ready static site for the Sera Club glacier experience.

## Entry Points

- `index.html` — primary landing page, using the “Recovery, engineered.” hero.
- `sera_club_catalog.html` — animated glacier catalog with desktop and mobile flows.
- `landing/catalog.html` — expanded product catalog page.

## Assets

- `assets/glacier-video-1/` — desktop glacier hero and catalog transition videos.
- `assets/mobile/` — mobile catalog frames and swipe transition videos.
- `assets/sera-catalog-listings-imgs/` — product vial imagery for catalog listings.

The previous black reveal concept has been removed from the deploy surface.

## Deploy

This is a plain static site. Deploy the repository root as-is with GitHub Pages, Netlify, Vercel, or any static host. No build step is required.
